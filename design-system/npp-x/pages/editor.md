# Editor chrome overrides

Dense desktop IDE shell (menus, tabs, status, find, marketplace).

- Keep run-green `#22C55E` / `#16A34A` as the only accent — no purple gradients.
- UI type: Plus Jakarta Sans; editor typeface stays JetBrains Mono via Monaco.
- Motion: 150–200ms on chrome; honor `prefers-reduced-motion`.
- Focus: 2px ring using `--color-ring` / accent; never `outline: none` alone.
- Density: 28–36px chrome rows; 8px spacing rhythm.
- Default theme id: `npp-2026` (dark slate). Light default alternative: `npp-classic`.
